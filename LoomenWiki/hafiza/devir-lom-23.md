# LOM-23 — Eksik kasa klasörü açılışta üst üste Kasa açılamadı pencereleri açıyor

## Ne yapıldı

Kasa klasörü açılamayınca açılan yerel hata pencereleri yerine uygulama içinde tek bir uyarı şeridi gösterilecek; aynı hata tekrar gelse de şerit tek kalacak, metin sade Türkçe olacak ve şeritten klasör yeniden seçilebilecek.

Açılışta aynı kasa için reopenVault en az iki kez çağrılıyor: persist geri yüklemesi (onRehydrateStorage, satır ~2642) + App.tsx'teki bootstrap (satır ~1146); geliştirme kipinde bootstrap iki kez koşabiliyor. Yerli pencereler sayfa yeniden yüklenince de kapanmıyor, bu yüzden her yeniden yüklemede 2 pencere daha birikiyor (Excalibur'daki 6 pencere = birkaç yeniden yükleme × 2; bu kısım çıkarım, kesin sayı doğrulanmadı). - YENİ SAF MODÜL Loomen/src/core/vault/openError.ts (React/i18n/Tauri/store import ETMEZ, node testinde koşacak): (a) `type OpenErrorCode = 'missing' | 'permission' | 'unknown'`. (b) `classifyOpenError(raw: string)`: metni küçük harfe indir; missing: 'no such file', 'cannot find the file', 'cannot find the path', 'not found', `(os error 2)`, `(os error 3)`; permission: 'permission denied', 'access is denied', 'forbidden path', 'not allowed', 'operation not permitted', `(os error 5)`, `(os error 13)`, `(os error 1)`; kalanı unknown. 'os error N' değerini /\(os error (\d+)\)/ ile yakala. (c) `openErrorDetail(e: unknown)`: Error ise message, değilse String(e); 300 karakterle kırp. (d) `openErrorMessageKey(code)`: missing → 'errors.vaultMissing', permission → 'errors.vaultNoAccess', unknown → 'errors.vaultOpenFailed'. (e) `vaultLabel(path: string)`: yolu hem '/' hem '\\' ile böl, sondaki ayraçları at, son parçayı döndür (Windows yolu 'C:\\Users\\x\\Notlar' → 'Notlar'); boşsa yolun kendisi. (f) `type VaultOpenError = { path: string; code: OpenErrorCode; detail: string }`. (g) `recordOpenError(prev: VaultOpenError | null, next: VaultOpenError)`: prev varsa ve path + code aynıysa prev'i AYNI referansla döndür (yeniden çizim ve yeni bildirim yok), değilse next. (h) `openErrorKey(e)`: `${e.code}:${e.path}`.
